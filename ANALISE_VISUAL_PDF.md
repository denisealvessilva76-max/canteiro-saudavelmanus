# Análise Visual do PDF - Canteiro Saudável

## Cores Identificadas

### Verde Oficial (Principal)
- **Cor**: #00A86B (Verde Escuro)
- **Uso**: Botões principais, headers, abas ativas, badges

### Cores Secundárias
- **Azul**: #0066FF (Botões secundários, links)
- **Vermelho/Rosa**: #FF6B6B (Alertas, avisos)
- **Amarelo/Laranja**: #FFB800 (Avisos moderados)
- **Roxo**: #9C27B0 (Ações especiais, tutorial)

### Cores de Fundo
- **Branco**: #FFFFFF (Fundo principal)
- **Verde Claro**: #E8F5E9 (Fundo de cards, seções)
- **Cinza**: #F5F5F5 (Fundo alternativo)

## Abas Principais (Bottom Navigation)

Ordem de esquerda para direita:
1. **Home** (Casa) - Ícone: home
2. **Ergonomia** (Pessoa em movimento) - Ícone: human-handsup
3. **Saúde** (Coração) - Ícone: heart
4. **Avisos** (Sino/Notificação) - Ícone: bell
5. **Perfil** (Pessoa) - Ícone: account

## Componentes Visuais

### Headers
- Fundo verde (#00A86B)
- Texto branco
- Ícone de voltar (arrow-left)
- Título em bold
- Subtítulo em texto menor

### Botões
- **Primário**: Verde (#00A86B), texto branco, arredondado
- **Secundário**: Branco com borda verde, texto verde
- **Terciário**: Cinza, texto escuro

### Cards
- Fundo branco
- Borda esquerda verde (4px)
- Sombra suave
- Padding: 15-20px
- Border-radius: 10-15px

### Badges/Tags
- Verde para sucesso/ativo
- Vermelho para alerta
- Amarelo para aviso
- Roxo para especial

## Telas Identificadas

### Home
- Desafios em cards com ícones
- Botão "Fazer Agora" verde
- Seção "Importante" com aviso

### Saúde
- Técnica de respiração 4-7-8
- Hidratação com copos visuais
- Garrafa animada mostrando progresso
- Histórico de consumo

### Comunicados
- Header verde com ícone de megafone
- Filtros: Todos, Urgente, Informativo
- Cards de comunicados com bordas coloridas
- Ícone de lixeira para deletar

### Painel Admin
- Header verde com "Painel Admin"
- Abas: Dashboard, Funcionários, Desafios, Comunicados
- Cards de funcionários com status
- Botão "Sair" no topo

## Elementos Especiais

### Progresso
- Barra verde com percentual
- Ícone de progresso ao lado

### Alertas
- Ícone de alerta (⚠️)
- Texto em vermelho ou amarelo
- Background colorido

### Notificações
- Sino com número de notificações
- Cor vermelha para urgente
- Cor verde para informativo

## Tipografia

- **Títulos**: Bold, 18-24px
- **Subtítulos**: 14-16px, cor #666
- **Corpo**: 13-14px, cor #333
- **Pequeno**: 11-12px, cor #999

## Espaçamento

- Padding padrão: 15-20px
- Margin entre cards: 10-15px
- Gap entre elementos: 8-12px
